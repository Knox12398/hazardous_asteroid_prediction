# hazardous_asteroid_prediction
Machine learning-based hazardous asteroid prediction using NASA Near-Earth Object (NEO) data.

🚀 Hazardous Asteroid Prediction

A machine learning project that predicts whether a Near-Earth Object (NEO) is potentially hazardous using NASA asteroid data. The project applies data preprocessing, exploratory data analysis, feature engineering, and classification algorithms to identify hazardous asteroids accurately.

📌 Project Overview

Near-Earth Objects (NEOs) are asteroids and comets whose orbits bring them close to Earth. Detecting potentially hazardous asteroids is important for planetary defense and risk assessment.

This project uses machine learning techniques to classify asteroids as:

Hazardous
Non-Hazardous

based on their physical and orbital characteristics.

📊 Dataset

Dataset Source: NASA Near Earth Objects Dataset (Kaggle)

Features include:

Absolute Magnitude
Estimated Diameter
Relative Velocity
Miss Distance
Orbiting Body
Other orbital parameters

Target Variable:

Hazardous (True/False)
